# Job Market Analysis | Power BI

## Project Overview

This project analyzes the job market for data-related roles to identify patterns in **job demand, salaries, industries, companies, job titles, technical skills, education requirements, and location**.

The analysis was performed using **Power BI**, with data preparation and transformation completed before developing interactive dashboards and visualizations.

The dataset contains **742 job postings across 42 features from 343 companies**, providing insights that can help job seekers better understand employment opportunities and skill requirements in the data job market.

---

## Project Objectives

The main objectives of this project were to:

- Identify states with the highest number of job opportunities.
- Compare minimum, maximum, and average salaries across states.
- Identify industries with the highest number of data science-related job postings.
- Determine companies with the highest number of job openings.
- Identify the most frequently advertised job titles.
- Compare salaries across high-demand job roles.
- Analyze technical skills required by employers.
- Examine the relationship between education and average salary.
- Explore additional job-market patterns using available features.
- Present the findings through interactive Power BI dashboards.

## Data Cleaning & Preparation

Before analysis, the dataset was reviewed and cleaned to improve data quality.

The preparation process included:

- Identifying missing and unavailable information.
- Handling `-1` values used as placeholders for unavailable information.
- Replacing appropriate placeholder values with null values.
- Removing a column containing only null values.

## Key Insights

- **California** recorded the highest number of job postings in the dataset, followed by Massachusetts and New York.
- Job availability and average salary varied considerably across states.
- **Data Scientist** was the most frequently advertised job title, followed by Research Scientist and Data Engineer.
- **Biotechnology & Pharmaceuticals** recorded the highest number of data science-related postings among the analyzed industries.
- Data-related opportunities were distributed across technology, healthcare, insurance, pharmaceuticals, and other industries.
- **Excel, Python, and SQL** were among the important technical skills represented in employer requirements.
- Cloud and visualization technologies were also represented in employer skill requirements.
- Higher educational requirements were associated with higher average salaries within the analyzed dataset.
- Private companies accounted for the largest share of job opportunities by ownership type.
- High-paying data opportunities were distributed across multiple industries rather than being limited to technology companies.

---

## Recommendations

- Consider both **job availability and salary levels** when selecting target locations.
- Focus on high-demand roles such as **Data Scientist, Research Scientist, and Data Engineer**.
- Develop a balanced technical skill set covering **analytics, programming, visualization, and cloud technologies**.
- Expand job searches beyond technology companies to industries such as biotechnology, pharmaceuticals, insurance, healthcare, and financial services.
- Compare both lower and upper salary estimates rather than relying only on average salary.
- Consider advanced qualifications strategically when targeting specialized or higher-paying positions.
